# nnu-thesis-typst
南京师范大学本科毕业论文模板-typst

本模板为南京师范大学本科毕业论文的 Typst 排版模板，基于 **地理科学学院 2023 年版** 格式要求制作，适用于中文毕业论文的撰写与排版。

## 为什么用 Typst 而不是 Word？

### 优势

- **自动排版**：字体、字号、行距、页眉页脚、图表编号、公式编号全部自动生成，无需手动调整
- **参考文献自动格式化**：配合 `gb7714-bilingual` 包，GB/T 7714-2015 格式一键生成
- **公式排版更美观**：原生支持 LaTeX 公式语法，美观度远超 Word 公式编辑器
- **版本控制友好**：纯文本文件，可用 Git 管理，方便回溯和协作
- **编译速度快**：毫秒级编译，修改后即时看到效果
- **跨平台**：Windows / macOS / Linux 均可使用
- **无格式冲突**：不像 Word 在不同版本、不同系统间会出现排版错乱
- **AI支持好**：可完全托管给codex或claude code等工具，进行自动化操作

### 局限性

- **期刊投稿受限**：部分核心期刊仍仅接受LaTex
- **格式版本依赖**：本模板基于地理科学学院 2023 年版格式要求制作，若学校后续更新格式标准，或跨学院使用，需自行核对并调整 `template.typ` 中的对应参数
- **学习成本**：需了解 Typst 的基本语法（但远比 LaTeX 简单，入门成本很低）.

## 快速使用

```bash
# 1. 下载release中的zip文件并解压到本地文件夹
# 2. 安装 Typst（https://github.com/typst/typst/releases）
# 3. 在 VS Code 中安装 Tinymist 插件
# 4. 修改 refs.bib 添加参考文献
# 5. 修改 chapters/ 下各章节内容
# 6. 编译
typst compile main.typ
```
